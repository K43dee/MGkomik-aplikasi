## ✨ Fitur Utama

| | |
|---|---|
| 🌐 | **WebView Bawaan** — Buka situs langsung di dalam aplikasi. Login, cookie, dan Cloudflare clearance beres otomatis. |
| 🚫 | **AdBlocker Pintar** — Iklan judi/slot & tracker diblokir total: request diblokir, elemen iklan dihapus dari halaman, sampai navigasi ke URL iklan pun digagalkan. |
| ⬇️ | **Download Chapter → CBZ** — Satu ketukan, semua halaman chapter terunduh otomatis menjadi file **CBZ** (format komik standar, kompatibel dengan KOReader, Perfect Viewer, dll). |
| 📚 | **Perpustakaan Offline** — Komik tersimpan rapi per judul. Buka lagi kapan pun tanpa internet. |
| 📖 | **Reader Gaya Webtoon** — Halaman tersusun vertikal dengan scroll kontinu, nyaman dibaca di HP. |
| 🔍 | **Zoom & Navigasi** — Pinch-zoom, double-tap, dan tombol prev/next untuk baca detail panel. |
| 📤 | **Share / Ekspor / Impor** — Bagikan chapter sebagai CBZ ke teman, atau impor file CBZ lain ke perpustakaan. |

## 🚀 Cara Pakai

1. **Buka aplikasi** — halaman mgkomik langsung tampil.
2. **Telusuri & buka chapter** yang mau dibaca.
3. Ketuk ikon **Download** — aplikasi mengumpulkan semua halaman chapter, lalu menyimpannya sebagai CBZ.
4. Buka **Perpustakaan** → pilih komik → pilih chapter → **baca offline**.
